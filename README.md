# ANAAG Guanajuato — demostración web

Sitio demostrativo navegable para la evaluación del portal deportivo de la Asociación de Natación y Aguas Abiertas de Guanajuato (ANAAG).

## Publicación con GitHub Pages

1. Abrir **Settings → Pages** en este repositorio.
2. En **Build and deployment**, elegir **Deploy from a branch**.
3. Seleccionar la rama **main**, carpeta **/(root)** y guardar con **Save**.
4. Al completarse la publicación, abrir: https://viajero09771.github.io/anaag-guanajuato-demo/

El sitio está en `index.html` y es autocontenido; no necesita WordPress ni base de datos para su demostración.

**Aviso:** Esta es una prueba de concepto, no un servicio oficial. Los tiempos y estados mostrados para perfiles de muestra no confirman afiliaciones o clasificaciones reales. El módulo de tienda no cobra ni procesa pedidos. No introducir información privada de menores de edad o credenciales reales.
